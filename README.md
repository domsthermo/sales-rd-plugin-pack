# Sales R&D Plugin Pack

A curated local Codex marketplace containing:

- GapAnalysis 1.1.0
- ProspectPro 1.3.1
- MeetingSummary 0.2.1
- premeetingprep 0.2.1 (package name: `scientific-meeting-prep`)

The marketplace leaves every plugin available for individual installation. It does not silently install or enable anything.

## Add this marketplace from GitHub

```sh
codex plugin marketplace add domsthermo/sales-rd-plugin-pack
```

Then restart the ChatGPT desktop app, open the Plugins Directory, choose **Sales R&D Plugin Pack**, and install the plugins you want.

## Add this marketplace from an extracted folder

```sh
codex plugin marketplace add /absolute/path/to/sales-rd-plugin-pack
```

To retrieve future changes:

```sh
codex plugin marketplace upgrade sales-rd-plugin-pack
```

This pack is a snapshot of the plugin versions listed above. Rebuild it when the source plugins are updated.
